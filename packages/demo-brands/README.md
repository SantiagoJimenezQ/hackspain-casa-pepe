# Fictional customer branding

Five original demo identities replace the customer names and logos; HappyRobot is unchanged. Colour families, industries, service dependencies, cities, affected users and priority rules are preserved. These names represent fictional companies in the scenario.

`demoCustomer` replaces display names, initials and logos for known persisted customer identifiers. `demoPresentation` additionally projects historical JSON and SSE text for the dashboard. It keeps identifiers and their arrays unchanged. The original database audit records are not rewritten; this is presentation pseudonymisation, not deletion or anonymisation of stored data. The geographic name United Arab Emirates is preserved.

`LEGACY_LOGOS` redirects old asset URLs to the new original SVG marks so saved runs and older clients do not show the retired corporate marks. The SVGs are hand-authored vector artwork in `apps/web/public/logos`; no brand assets, external fonts or image-generation services are used for these five marks. The geometry is designed to remain legible in the map's 14 px logo slots.
